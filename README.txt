KTM — Persian company website

Open index.html to view the website. Keep all files and the assets folder together.

Pages: index.html, products.html, about.html, contact.html

To update contact details, edit contact-details.js and enter values between the empty quotes for phone, email, address and hours. The contact page automatically displays those values. Use international digits for the phone value, e.g. +98 followed by the real number.

The inquiry form prepares text for copying. It does not send or store messages. A live submission service can be connected later.

The site uses the supplied product photographs. Model compatibility and detailed technical specifications should be confirmed before adding them.

The Persian Vazirmatn font loads from Google Fonts when online; Tahoma is used as a fallback.
